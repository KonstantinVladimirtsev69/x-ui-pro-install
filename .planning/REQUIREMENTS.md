# Requirements

## REQ-01: Dynamic Client Name & IP Suffix
- **REQ-01.1**: Скрипт не должен использовать фиксированное имя `first` для первого клиента.
- **REQ-01.2**: Суффикс имени клиента формируется из последнего октета IPv4 адреса сервера (`-${IP4##*.}`).
- **REQ-01.3**: При отсутствии пользовательского ввода по умолчанию используется `${HOSTNAME_SHORT}-${IP_OCTET}` (например, `play2go-236`).
- **REQ-01.4**: При ручном вводе имени клиента к нему принудительно дописывается суффикс `-${IP_OCTET}` (без дублирования, если суффикс уже был указан вручную).
- **REQ-01.5**: Имя клиента очищается от спецсимволов и пробелов, оставаясь безопасным для URL/path.
- **REQ-01.6**: Имя клиента корректно проставляется в SQLite (`inbounds`, `client_traffics`), веб-странице подписки и ссылках для клиентов.
