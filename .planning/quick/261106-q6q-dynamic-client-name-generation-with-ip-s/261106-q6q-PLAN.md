# Plan: Динамическая генерация имени первого клиента с суффиксом IP

## Goal
Заменить статический идентификатор `first` на динамический: если пользователь вводит имя вручную — использовать его с обязательным добавлением `-${IP_LAST}`, если оставляет пустым — использовать `${HOSTNAME_SHORT}-${IP_LAST}`.

## Tasks

### Task 1: Написание тестов логики генерации и санитизации (RED)
- **Files**: `tests/test_client_name.sh`
- **Action**: Написать bash-тест, покрывающий:
  1. Дефолтное имя: при отсутствии ввода берется `${HOSTNAME_SHORT}-${IP_LAST}`.
  2. Ручной ввод без суффикса: `ivan` -> `ivan-${IP_LAST}`.
  3. Ручной ввод с уже имеющимся суффиксом: `ivan-${IP_LAST}` -> `ivan-${IP_LAST}` (без дубля `ivan-236-236`).
  4. Санитизация: удаление пробелов, спецсимволов, перевод в валидный URL-идентификатор.
- **Verify**: Запустить `bash tests/test_client_name.sh` и зафиксировать падение до реализации логики.

### Task 2: Реализация логики в `install.sh` и `x-ui-pro.sh` (GREEN)
- **Files**: `install.sh`, `x-ui-pro.sh`
- **Action**:
  1. В `x-ui-pro.sh`:
     - Добавить парсинг аргумента `-client_name`.
     - Реализовать функцию `resolve_client_name`: извлечение последнего октета IPv4 (`${IP4##*.}`), очистка и нормализация имени, добавление `-${IP_OCTET}` при отсутствии.
     - Заменить все упоминания `first` в SQL-запросах (`client_traffics`, `inbounds` settings: `email`, `subId`), путях веб-страницы подписки и выводе информации в терминал на `$client_name`.
  2. В `install.sh`:
     - Определить IP сервера и предложить имя по умолчанию `[${HOSTNAME_SHORT}-${IP_LAST}]`.
     - Запросить у пользователя имя первого клиента (с возможностью нажать Enter).
     - Передать итоговый `-client_name` в вызов `x-ui-pro.sh`.
- **Verify**: Запустить `bash tests/test_client_name.sh` и убедиться в прохождении всех тестов.

### Task 3: Верификация и синтаксический контроль
- **Files**: `install.sh`, `x-ui-pro.sh`
- **Action**: Проверить валидность синтаксиса обоих скриптов через `bash -n`.
- **Verify**: `bash -n install.sh && bash -n x-ui-pro.sh && bash tests/test_client_name.sh`
